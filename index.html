Customizing the summary

The summary is built from two text boxes above: the overall template (the full message, with a header, the accomplishments/deductions/feedback sections and the score line) and the item line format (how each single rubric line looks inside those sections). Edit either one and click Save changes — the Evaluation tab will use your version from then on.

To design a different style, just rewrite the template text using the placeholders below anywhere you like — reorder them, remove sections you don't need, or add your own wording around them. To go back to the built-in wording, retype it manually (there's no "several saved templates" list — only one template is active at a time).

PlaceholderWhat it inserts
{{fields}}Call detail lines (Agent, QA evaluator, Caller, Ticket ID, Call reason, Order ID) — Order ID is skipped when empty, the rest show N/A
{{agent}} {{evaluator}} {{caller}} {{ticket}} {{order}} {{reason}}Just that one field's value, on its own
{{deductions}}A "Deductions" heading plus every rubric marked ✕, grouped by section. Skipped entirely (no heading) if there are none.
{{feedback}}A "Feedback" heading plus every rubric flagged ⚠, grouped by section. Skipped entirely (no heading) if there are none.
{{accomplishments}}An "Accomplishments" heading plus the met rubrics picked as accomplishments (up to 3), grouped by section. Skipped entirely (no heading) if there are none.
{{focus}}A "Focus points" heading plus the focus points picked for the evaluation. If the template doesn't use it, they go right after the accomplishments.
{{score}} {{earned}} {{possible}}The score out of 100, and the raw points earned / possible
{{zeroline}}The automatic-zero warning line, only when triggered

In the item line format box: {{icon}} is ✓ / ✕ / ⚠, {{label}} is the short rubric name, {{text}} is its met/not‑met/reason text, and {{pts}} already includes its own suffix — "(-Npts)" for deductions or "(Auto‑Zero)" for zero call drivers, and nothing for accomplishments and feedback.
